# Planetary-Responsibility in a pixel art style with a visual design reference of old retro games. The project has five pages listing different types of gifts associated with the listed responsibility.

Access the site here:
https://kveeic.github.io/Planetary-Responsibility/

1. What were you put here to do (Your Mission / Planetary Responsibility – One Word)
To Breakthrough
2. Gifts you have that influence your purpose (5 things)
List: Vitality, Forbearance, Adaptability, Ingenuity, Discipline
3. Two ways you can utilize each gift in different roles (2 for each gift)

#User commands
Clicking the numbers changes the page which reveals different Gifts & Roles.
